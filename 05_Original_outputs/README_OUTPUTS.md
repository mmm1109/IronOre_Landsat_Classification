# Original Classification Outputs

This folder contains the original classified raster outputs generated during the study using ArcMap and QGIS/SCP.

## Classification outputs

The four classification methods used in the manuscript were:

- Spectral Angle Mapping (SAM)
- Maximum Likelihood Classification (MLC)
- Random Forest (RF)
- Support Vector Machine (SVM)

The corresponding original classified rasters are stored in this folder.

Expected files are:

- `SAM_original.tif`
- `MLC_original.tif`
- `RF_original.tif`
- `SVM_original.tif`

Include only the genuine original raster outputs that were produced during the study.

## Software used

- MLC was performed in ArcMap 10.8.2 using the Spatial Analyst Maximum Likelihood Classification tool.
- SAM, RF, and SVM were performed in QGIS using the Semi-Automatic Classification Plugin (SCP).

## Purpose of these files

These rasters represent the original software-generated classification outputs associated with the results reported in the manuscript.

They are provided to:

- document the original classification results;
- support comparison among the four classification methods;
- provide transparency regarding the mapped outputs used in the study;
- allow visual and spatial inspection of the reported classification results.

The reported confusion matrices and accuracy metrics are presented in the manuscript and are not duplicated in this folder.
