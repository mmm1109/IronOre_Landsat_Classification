THIRD-PARTY SOFTWARE ATTRIBUTION

Repository:
IronOre_Landsat_Classification

This repository accompanies the manuscript:
"A Comparative Evaluation of Potential Iron Ore Zone from Satellite Data using Machine Learning and Conventional Approaches"

The classifications reported in the study were performed using third-party GIS software. The authors did not develop the underlying classification algorithms.

1. ArcGIS Desktop / ArcMap / ArcPy Spatial Analyst
--------------------------------------------------
Developer: Esri

Use in this study:
Maximum Likelihood Classification (MLC), implemented through ArcMap 10.8.2 Spatial Analyst.

The file:
04_Code/01_MLC_ArcGIS.py

documents the public ArcPy MLClassify tool call and the study-specific parameter settings.

Esri's internal Maximum Likelihood Classification source code is proprietary and is NOT copied, redistributed, or claimed as author-developed code in this repository.

ArcGIS and ArcPy remain subject to Esri's software licence terms.
